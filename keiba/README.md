# 🏇 中央競馬 予想ノート

JRA（中央競馬）のレース予想用ウェブアプリです。ビルド不要・依存ライブラリなしの静的サイトです。

## できること

- **出走馬入力**：馬名・騎手・斤量・単勝オッズ・近走着順・上がり順位・各種適性（1〜5）・調教評価（A〜D）・馬体重増減・レース間隔
  - 出馬表のテキストを一括貼り付け（`馬番 馬名 騎手 斤量 単勝 近走`）
  - 頭数に応じて JRA ルールで枠番を自動計算し、枠色で表示
- **予想**：各ファクターの重み付き合計で能力指数を出し、勝率に変換。単勝オッズ（市場評価）と合成して推定勝率・複勝率・期待値を算出
  - 印（◎○▲△☆）を自動付与。☆ は期待値 1.0 以上の人気薄（単勝10倍以上）
  - 競馬場・芝ダ・距離から枠バイアスを自動推定（手動変更可）
  - 馬場が重いほど道悪適性の重みが自動で上がる
- **買い目**：予算を入れると「単複／馬連流し／3連複1頭軸流し／3連単フォーメーション」を的中率比例で100円単位に配分
  - 馬連・ワイド・馬単・3連複・3連単の上位組み合わせと理論オッズ（1÷的中率）を表示
  - 着順確率は Harville モデル（2・3着は Benter 補正）で計算
- **重み調整**：スライダーで各ファクターの重みを変更するとリアルタイムで再計算
- **収支記録**：着順・購入額・払戻額を入れると、◎の勝率・複勝率、回収率、収支を集計
- データは localStorage に保存。JSON で書き出し／読み込み可能

### スマホのホーム画面に追加する

- **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：右上メニュー → 「アプリをインストール」または「ホーム画面に追加」

追加するとアプリのように全画面で起動し、一度開いた後は電波がなくても使えます。

## 競馬ブックからの取り込み

出走馬編集の「貼り付けで取り込む」に、ページを選択→コピーしたテキストを貼り付けます（種類は自動判別、手動指定も可）。
解析結果をプレビューで確認してから「反映する」で出走馬に書き込みます。馬名（なければ馬番）で照合します。
ページ上部のレース名・日付・競馬場・R・芝ダ・距離・馬場・格付けも一緒にコピーすると、レース条件も自動で入ります（一覧の「貼り付けから作成」で新規レースを作ってそのまま取り込めます）。

| 種類 | 取り込む内容 |
| --- | --- |
| 過去走（馬柱） | 着順・距離／コース／道悪の成績から適性(1〜5)、前走の上がり順位、レース間隔、斤量。未登録の馬は新規登録 |
| 調教 | 短評の言葉・併せ馬の先着／遅れ・ラスト1F・矢印から調教評価(A〜D)。短評も保存 |
| 厩舎コメント | 前向き／後ろ向きの言葉から陣営評価(1〜5)。コメント本文も保存 |
| オッズ | 単勝・複勝・人気 |

予想画面では印をタップして自分の印に変更でき（「消」は除外）、買い目も組み直されます。馬名タップで取り込んだ詳細と各ファクターの評価を確認できます。

解析はキーワードと正規表現による推定です。ページの体裁によっては取りこぼすことがあるので、プレビューと出走馬表で確認・修正してください。

## はじめかた

1. 「＋ 新しいレース」でレース条件（競馬場・距離・馬場など）を入力
2. 出走馬を入力（馬名・単勝オッズ・近走だけでも可。出馬表の一括貼り付けも可）
3. 「予想する」で印・推定勝率・期待値・買い目を表示

初回起動時はサンプルレース「サンプル記念（例）」が入っているので、まずそれを開くと完成形が見られます。

## ローカルで動かす

```sh
python3 -m http.server 8000
# http://localhost:8000/keiba/ を開く
```

> ※ 予想は入力データに基づく統計的な目安で、的中を保証するものではありません。馬券の購入は20歳以上・余裕資金の範囲で。
