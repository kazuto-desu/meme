# 👁 眼球トレーニング

ブラウザで動く眼球トレーニング用ウェブアプリです。ビルド不要・依存ライブラリなしの静的サイトで、`index.html` をブラウザで開くだけで使えます。

## トレーニング

| モード | 内容 |
| --- | --- |
| 追従運動 | 動く点を目で追う（横・縦・斜め・円・8の字を順番に） |
| ジャンプ | ランダムに出るターゲットを素早くタップ。命中率と平均反応時間を記録 |
| 周辺視野 | 中央の ✛ を見たまま、一瞬光った方向を矢印キー／ボタンで答える |
| 遠近ピント | 画面の小さな文字 → 指先（約20cm） → 画面 → 遠く、と交互にピントを切り替える |
| リラックス | まばたき → 閉眼 → 遠くを見る、のガイドで目を休める |

- 時間（30秒 / 1分 / 2分）とスピード（ゆっくり / ふつう / はやい）を選べます
- 設定と直近の記録はブラウザの localStorage に保存されます
- `Esc` キーまたは「終了」ボタンで中断できます

## ローカルで動かす

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```
